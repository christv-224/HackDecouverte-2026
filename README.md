# Search & Find

**Community-based lost object finder website**

`HTML` · `CSS` · `Bootstrap` · `JS`

---

## Problem

The problem this website hopes to resolve is lost objects and many of its consequences - anyone knows how frustrating losing valuables is. The STM alone collects between 48,000 and 61,000 lost objects per year. If we scale that across all of Montreal and the number becomes staggering - wasted money, unnecessary stress, and in some cases, avoidable pollution.

## Solution

The solution is community: We can turn every Montrealer into a potential helper. There are 3 simple pages:

- **[Home]** - Connect and view basic stats related to the app.
- **[Add]** - Add objects you find. Title, description, tags, date & contacts are saved.
- **[Search]** - Search what you lost, and hopefully find it. Based on title, description, tags & date.

## What's Next

We plan to add the following:

- A proper connection page and identification
- A map to view lost objects you are tagged on
- Image storage to save, view, and take pictures

## Challenges

Knowing it was our first hackathon, we didn't know it was allowed to plan beforehand — next time, we'll come with wireframes ready. We also spent time learning Git/GitHub collaboration, branches and conflicts. Most of our time went into CSS and Bootstrap, which was new for all 3 of us. We didn't have time to touch JavaScript at all.

## What We Learned
